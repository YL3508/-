# Demo 3｜小組流程確認版

版本日期：2026-10-02。來源：個人分支 `mandy/rule-walkthrough`；本版以已併入 `dev` 的 Demo 2 為基礎，另校對 Demo 3 走查內容。

這版供四位組員用同一份可操作原型確認角色流程、畫面資訊與待決規則。走查工具是檢查方式；Demo 3 是整份網站原型。請勿把展示設定當成已完成的後端、資料庫或正式 API。

## 怎麼開啟

1. 解壓縮後，雙擊 `規則確認會.html`，進入含右側十一步走查工具的 Demo 3。筆電可離線使用。這版筆記與 Demo 2 分開保存；若 Demo 2 已有筆記，請先匯出 Markdown。
2. 依右側步驟按「打開本步畫面」，親手操作，再記錄與預期不同的地方。
3. 完成後按「下載 Markdown」或「複製回饋摘要」，將結果交給團隊討論。重新整理會重設模擬案件；整理好筆記後再重整。
4. 若只想看網站，開 `index.html`；若需要單一檔案，開 `離線展示.html`。後者也可在網址後加 `?walkthrough=1` 進入走查模式。

## 本版相對 Demo 2 的變更

| 範圍 | 可操作或可查看的內容 |
|---|---|
| 一般學校 | 競賽報名送出前有資料摘要、返回修改、確認送出與完成提示。 |
| 承辦學校 | 競賽須知與評分標準必填；可沿用歷史設定、核對摘要後儲存草稿。 |
| 名額 | 每場競賽的額外上限可選填，顯示示意剩餘量；尚不限制實際報名。 |
| 名冊 | 全部案件與「目前審核通過」名冊分開；核准後畫面即更新。 |
| 歷史競賽 | 可查閱預建的已結案紀錄；不提供結案操作，結案及修改規則待討論。 |
| 走查 | 十一步導覽，新增已結案歷史查詢，公開公告步驟改由承辦發布再切訪客；可記錄選項與問題、匯出回饋。 |

## 明確限制

- 一般學校與承辦學校共用一筆假案件；承辦自己的學校報名仍是空狀態示例。
- 歷史設定、名額草稿與案件資料只存在目前頁面記憶體；重新整理會還原。
- 名額占用、時窗、班級數判組、結案條件尚未接進核心案例，也未核定為正式規則。
- 出場序、成績與公開結果是預建情境，不由剛才的報名案件產生。
- PDF／Excel／Word 正式文件、真實登入、資料庫與 API 尚未在此原型完成。

團隊回饋請寫成「角色／步驟 → 做了什麼 → 畫面顯示什麼 → 期待什麼」，並註明是程式錯誤、操作不順，還是規則待討論。正式需求仍以 `docs/requirements/需求書原文.md` 與原始 PDF 為準。
