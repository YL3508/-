# Demo 3 小組確認回饋

此為小組走查紀錄；選項不會改變 Demo，未標示正式核定的內容不得當作正式需求。

Demo 案件狀態：ENG-001 · 已核准。

## 逐步討論

1. **共用學校工作區**（可操作導覽；已確認的團隊決議）
   - 問題：承辦者保留一般學校功能時，這樣的入口是否清楚？
   - 小組選項：清楚，維持同一工作區
2. **建立競賽**（展示草稿；PDF 第 4 頁；REQ-038）
   - 問題：重辦同類競賽時，歷史設定應怎麼使用？
   - 小組選項：複製成新草稿，再逐項確認
3. **組別、名額與時窗**（展示草稿；PDF 第 3–5 頁；REQ-023、040–044）
   - 問題：報名名額何時被占用？
   - 小組選項：審核通過後才占用
4. **學校送出報名**（可操作核心流程；PDF 第 4–5 頁；REQ-041–046）
   - 問題：「一筆報名」應代表什麼？
   - 小組選項：每場競賽自行設定
5. **承辦要求補件**（可操作核心流程；PDF 第 5 頁；REQ-045）
   - 問題：如果承辦學校也報名同一場競賽，誰能審自己的案件？
   - 小組選項：可自審，但留操作紀錄
6. **補件中的名冊**（摘要示例；PDF 第 5 頁；REQ-045–046；團隊已選名冊 A）
   - 問題：是否符合已確認的名冊 A：只列目前審核通過案件？
   - 小組選項：未選擇／待確認
   - 補充：這題目看不懂
7. **學校查看並重送**（可操作核心流程；PDF 第 5 頁；REQ-045）
   - 問題：補件時學校可以改哪些內容？
   - 小組選項：可改附件與參賽資料
8. **再次審核並核准**（可操作核心流程；PDF 第 5 頁；REQ-045）
   - 問題：核准後如發現資料錯誤，應如何處理？
   - 小組選項：退回補件並重審
9. **核准後的名冊**（摘要示例；PDF 第 5 頁；REQ-046）
   - 問題：名冊匯出前還需要哪些確認？
   - 小組選項：未選擇／待確認
   - 補充：承辦學校審核報名通過後，系統自動匯出
10. **已結案歷史查詢**（預建情境；團隊已選結案 C；結案方式待決）
   - 問題：目前只讀的歷史畫面能否支援承辦回查？
   - 小組選項：可先使用
   - 補充：可備註不能動
11. **發布並查看公開結果**（預建情境；PDF 第 5 頁；REQ-047–049）
   - 問題：得獎公告的對外欄位如何決定？
   - 小組選項：待小組討論
   - 補充：設定完全不公開，僅登入後查看
