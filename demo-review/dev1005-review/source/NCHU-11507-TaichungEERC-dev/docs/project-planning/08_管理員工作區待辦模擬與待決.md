## 需求來源

- 組員建議：登入摘要、未完成紅點與件數、展開及導流、文字清單與日曆分流、網站管理子選單、首頁瀏覽人數。**這些 UI 與提醒規則不是 PDF 原文已定規格。**

## 本輪 Demo 可操作範圍

1. 模擬登入管理員時顯示可展開的「待處理事項」摘要。每則有事項、截止時間或收到時間、處理入口；也可從首頁重新打開摘要。
2. 側欄的對應選單顯示未完成件數；進入分頁或閱讀摘要不清除。於分頁按「完成示範處理」後才減少件數，一鍵重設恢復。
3. 首頁預設文字清單，分「近期到期／今日待辦」和「收到的待處理申請」。日曆只放有截止日期的事項，申請仍在文字清單。
4. 側欄新增「網站管理」分組及「系統與權限」「網站內容」「人才資料庫」。另以業務作業分組放調查、計畫與營隊入口。
5. 首頁顯示四項固定瀏覽人數（當前 12、本日 86、本月 320、本年 1,280），明示是假資料。

示範今日固定為 **2026/10/02**；4 筆待辦、時間、學校和數字都是假資料。`admin-data.js` 是資料層，`admin.js` 是畫面與互動。完成示範處理只更新記憶體中的待辦狀態；不授予實際權限、不產生正式審查結果，重新整理會還原。組員後續提供的管理員 HTML 需另行比對和整合，不能把此版當成最終管理後台。

## 驗證與限制

- `node test-admin.cjs` 驗證讀取不清除、完成才減少件數、分流及重設。
- 瀏覽器走查（2026-10-02，localhost 原型）：管理員登入顯示 4 件彈窗；展開及「前往處理」後仍為 4 件；按「完成示範處理」後變 3 件，對應側欄數字清除；首頁四項瀏覽數字可見；日曆僅有 2 筆設定期限的工作，申請仍在文字清單。390px 寬度的文件未橫向溢出，日曆在其區塊內可橫向捲動。重新整理管理員網址回到模擬登入頁；在瀏覽器完成一筆事項後按一鍵重設，網址回到 `#home`，再次登入管理員時恢復 4 件待辦。
- 正式版還需要登入／授權、任務來源與 API、多人併發、待辦狀態歷程、通知通道、統計服務及無障礙驗收。
