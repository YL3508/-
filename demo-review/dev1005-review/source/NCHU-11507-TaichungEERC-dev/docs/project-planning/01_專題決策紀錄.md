## 二、專題交付的共通解讀

- 「10/13 前可操作」是開發計畫目標，須由實際測試與成果證明；不等同需求書採購案的正式驗收。
- 需求書要求全站功能、RWD、雙語等；專題以 10/13 可操作與 10/20 展示為目標，任何以測試資料替代正式外部介接的地方都須說明。
- 系統管理員在競賽流程的核心工作為**承辦授權**及依競賽需求**新增報名／指導老師／行政支援老師欄位**；競賽建立、報名審核、抽籤、成績等由承辦學校操作，除非另有明確決議。
