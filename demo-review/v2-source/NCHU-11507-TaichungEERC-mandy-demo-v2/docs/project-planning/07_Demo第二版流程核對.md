## 第二版順序建議（尚非新增業務規則）

1. 先走通一般學校與承辦本校共用報名畫面，區分「本校參賽」和「承辦審核」的案件範圍。
2. 補齊 PDF 明定欄位；以同一份模擬資料串聯競賽設定及報名。未定規則保留明確標記。
3. 處理阻擋流程的問題，再擴充其他模組可操作程度，持續標示真實與模擬差異。
4. 依確認的設計基準統一公開網站與工作台，保留兩者不同的使用目的。

## UI／UX 方向草案

- 公開網站：延續團隊喜歡的親切、活潑教育風格，先讓訪客理解資訊與入口。字體、資訊層級與留白優先，不新增學生登入或單字練習。首頁優先最新消息、競賽與活動資訊（2026-09-30 已確認）。
- 工作台：以學校承辦人員辦公情境為主，穩定的側欄、清楚的本校／承辦標示、可掃讀的案件列表與表單、可追蹤的補件意見。同帳號同工作區是已確認需求。
- 共用：按鈕、欄位標籤、狀態、錯誤、鍵盤焦點及回饋一致；狀態不能只靠顏色區分。行動版需調整導覽與表格，不只是縮小桌面。
- 已確認順序：先改完流程與操作，再來改介面。視覺製作方式尚未選擇，不預先設定。此文件不是已核定的視覺規格，本輪不修改介面外觀。
