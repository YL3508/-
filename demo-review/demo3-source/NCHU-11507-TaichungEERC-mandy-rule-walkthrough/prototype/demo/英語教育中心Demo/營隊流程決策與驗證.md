# 營隊訪客流程｜2026-10-01

## 來源

REQ-056、REQ-057，需求書 PDF 第 6 頁：管理員設定活動、場次、欄位與時窗；民眾免帳號報名、檢核重複、正備取餘額、全滿停止報名。REQ-058 Excel 匯出與 REQ-059 管理端刪除不在本輪實作，等管理員組員提供 HTML 整合。

## 團隊確認

- 列表先提供主題、年級、日期時間、地點、費用、報名期間及名額，詳情提供內容與接送。
- 半日、一日、多日為展示範例，實際日期、每日時間與報名期間分開。
- 孩子姓名、學校、學號、年級、聯絡人姓名、電話必填。學校從清單選擇；學號以字串保留前導零。不知道學號需先向學校確認。
- 同梯次以學校 ID＋學號判重；不同梯次可報。這不能驗證填寫者身分。Email 不列必填，本輪不收集。
- 活動額外欄位依管理員設定；本輪以 camp-data.js 模擬欄位設定。
- 預覽不占名額；確定送出重新檢查時窗、資料、判重及名額。正取滿可進備取，全部滿則拒絕。提示預覽後可能改為備取。
- 返回修改與送出失敗保留資料；成功顯示編號與正備取結果。防連按與同一送出 token 重送。
- 可列印摘要；不提供線上查詢。列印省略學號、聯絡人、電話及額外欄位。備取明示尚未錄取。

## 展示假設與限制

固定模擬時間 2026/10/01 15:00（不是正式時鐘）；各日期、兩所示範學校、適用年級、免費、正備取容量及預占數皆是假資料。半日兩梯次示範正取／備取、一日示範全滿、多日另有開放及截止梯次。姓名與電話只使用虛構內容。

camp-data.js 為獨立資料存取層，camp.js 為畫面層。記憶體資料重新整理即清除；不同分頁不共享。正式 API 必須由伺服器時鐘、資料庫交易、同梯次＋學校＋學號唯一性與 idempotency 保證併發正確，不能沿用前端判斷當安全防線。取消、遞補、保存期限與真實學校清單仍待定，不自行實作。

全站重設一併清除營隊報名、草稿、完成摘要、預覽、送出 token、語言與搜尋；舊 epoch 不可送出。
