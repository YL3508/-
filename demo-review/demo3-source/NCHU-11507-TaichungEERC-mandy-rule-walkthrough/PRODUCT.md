# 臺中市英語教育資源中心｜產品背景

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- 訪客：瀏覽最新消息、競賽、活動、中心與公開資源。公開首頁優先協助找到最新消息、競賽與活動資訊（使用者於 2026-09-30 確認）。
- 學校承辦人員：填寫報名、補件、調查、計畫及經費概算，上傳教學資源與成果。
- 具競賽承辦權限的學校人員：在同一學校工作區使用額外承辦選單，管理所承辦競賽；保留本校一般學校功能。
- 系統管理員：管理內容、學校、帳號與授權，以及調查、資源、計畫審查及營隊等設定。

## Product Purpose

整合臺中市英語教育資源中心的公開資訊及學校行政協作。專題以需求書為主、已確認團隊決議與圖稿為輔；可操作的 Demo 用來找出缺漏，再逐步接近正式系統，不以展示假資料取代正式完成。

## Operating Context

- 正式專案採 Vue 3、Vue Router、Pinia、Vite 前端，以及 Laravel JSON API 後端。
- `prototype/demo/英語教育中心Demo` 為獨立 HTML/JavaScript 原型；含離線展示檔，使用記憶體假資料。重新整理會還原，不代表正式資料庫行為。
- 本輪在個人分支 `mandy/demo-v2` 進行流程走查。先確認流程、欄位、權限與操作，再統一 UI／UX；外觀改版已依使用者 2026-09-30 的意見延後。

## Capabilities and Constraints

- 需求原案：[Markdown](docs/requirements/需求書原文.md)／[PDF](docs/requirements/source.pdf)；狀態與驗證證據記錄於 [需求核對表](docs/requirements/需求核對表.md)。
- 四種使用身分不代表四套獨立登入流程。一般學校與承辦共享工作區；系統自動判斷不是登入角色。
- 不新增學生登入、單字練習或原文未要求的學習平台功能。民眾營隊報名免登入。
- 正式時窗細節、名額計算、補件期限、計分同分處理等待決規則不得由原型假設直接定案。
- 認證、API、資料庫、檔案產出與資料隔離需正式實作及驗證；單靠畫面不能宣稱完成。

## Brand Commitments

名稱為「臺中市英語教育資源中心」。公開網站可延續使用者喜歡的活潑、親切教育風格；花蓮參考網站只提供視覺參考，不能據此新增功能。工作台服務學校行政人員的日常作業。字體、色彩與版型尚未核定，本輪不改版。

## Evidence on Hand

原始需求 PDF、完整文字轉錄、團隊決策、泳道圖、網站架構圖、既有原型及驗證紀錄均在專案內。活動、人物、競賽資料是示範，不是真實成果。正式中心素材及授權書公版尚待提供，不自行編造。

## Product Principles

- 每項功能追溯至需求原案或明確決議。
- 先走通任務，再處理視覺表現。
- 同一案件跨角色保持一致，本校資料與所承辦競賽資料範圍清楚。
- 明確區分原型、正式實作與已驗證結果。

## Accessibility & Inclusion

需求書要求 RWD、前台 AA 無障礙標章及雙語欄位。後續設計需檢查鍵盤焦點、表單標籤、可讀性、狀態辨識與窄螢幕操作；這些設計檢查不等於已取得標章。雙語內容缺漏的回退方式尚待確認。
