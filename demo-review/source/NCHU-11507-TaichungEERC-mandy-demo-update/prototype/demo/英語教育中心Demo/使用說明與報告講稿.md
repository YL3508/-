# 臺中市英語教育資源中心 · 明天報告版

## 怎麼開啟

最簡單：雙擊「離線展示.html」。整份網頁、插畫與程式已內嵌，不需網路、安裝或啟動伺服器。建議用 Chrome、Edge 或 Safari 開啟。

開發版本：保留本資料夾全部檔案，雙擊 index.html。data.js 管理模擬資料與案件狀態，app.js 管理畫面與操作，style.css 管理視覺。此版為原生 JavaScript，沒有引入 Vue；將來可將畫面拆成 Vue 元件，保留 repository 介面再改接 API。不是已完成的 Vue 或 Laravel 專案。

只保留目前頁面的資料：切換角色不會遺失；重新整理、關閉頁面或按重設會清除。每次報告先按「重設展示」。

## 3–5 分鐘報告腳本

1. 首頁（30 秒）：我們整合教育資源、活動報名與學校行政協作，公開入口親切明亮，工作區重視清楚易用。
2. 點「進入學校工作區」（45 秒）：先直接送出，展示必填提示；填示範學生、示範老師並選示範附件後送出。這是 ENG-001 案件。
3. 點「切到承辦審核」（45 秒）：填「請補上授權書簽名頁。」並按要求補件。說明承辦負責審核，系統記錄狀態及意見。
4. 點「切到學校查看進度」（30 秒）：學校看到同一筆案件的補件意見，選擇簽名完成的附件並重新送出。
5. 切到承辦，填「文件齊全，核准參賽。」並核准（30 秒）：檢查案件歷程與已通過數量。
6. 點「查看後續展示情境」（30 秒）：明確說明後段使用獨立的預建出場序與成績示例，尚未實作抽籤與計分。點成績與公告示例，再發布示範公告。
7. 點「以訪客查看」（20 秒）：公開畫面只顯示示範學校、組別、順序、獎項，不含審核意見或補件內容。
8. 結尾（20 秒）：今天完成前端模擬流程；兩週後目標是完成後端、資料庫與 API 串接，仍須確認規則並進行整合測試。

現場若無法操作，可按 screenshots 編號順序使用 PNG 畫面講解。

## 已確認的需求

- 公開首頁、各模組入口與四種身分工作區。
- 一般學校與承辦學校共用同一筆示範案件狀態。
- 報名、要求補件、重送、核准及案件歷程可操作。
- 承辦身分保留一般學校工作區；本版僅完整操作示範國小 A 的一筆案件，B 校自己的報名流程尚未實作。
- 調查、教學資源與成果、計畫填報、營隊、管理設定提供標示清楚的範例。
- 離線操作、一鍵重設、明亮童趣首頁、清楚的教師工作區。

## 展示假設（不是正式規格）

報名時窗固定開放、名額足夠、校別與組別符合；一校一筆案例；承辦已預先授權；補件沒有截止時間；所有學校、師生、附件與成績均為虚構。

## 團隊定案：A 方案（2026-09-30）

承辦學校同一帳號使用同一工作區，左側分「學校作業」與「競賽承辦」，不需要再次登入或切換權限模式。展示工具的 A／B 校切換是模擬不同學校帳號。

由公開頁登入入口選「模擬承辦登入」，進入承辦工作台；可查看競賽建立／編輯、組別與報名設定、報名審核、報名資料／報表、出場序抽籤、成績與序位、得獎公告。設定草稿可暫存，重新整理或重設即還原，且不套用至固定報名案例。正式文件、抽籤計算、成績計算及可配置公告未完成。本校案件僅空狀態示例，多校報名尚未擴充。
